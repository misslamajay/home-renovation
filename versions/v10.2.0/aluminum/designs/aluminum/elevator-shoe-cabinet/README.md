# 电梯鞋柜 · 阴角框架 V1

两侧从同一个 90° 墙角沿两面墙量起，尺寸均为外廓毫米尺寸。

| 部位 | 沿墙长度 | 深度 | 外高 |
| --- | ---: | ---: | ---: |
| 左侧框架 | 1380 | 400 | 2350 |
| 右侧框架 | 1350 | 400 | 2350 |

沿用 30 × 30 mm 铝型材。400 × 400 mm 转角共用，两段不重复占用同一空间。转角以外，左侧外廓延伸 980 mm，右侧延伸 950 mm。

本版搭出立柱、顶框和底框。转角立柱及横梁共用；水平梁在立柱侧面相接，避免两套框架叠穿。外高 2350 mm，顶框和底框各占 30 mm，当前框架内高 2290 mm。

三维图可拖动旋转、滚轮或双指缩放，可切换整体、俯视、左侧正视和右侧正视；尺寸页包含俯视拼接与两侧立面。槽形用于表达型材外观，连接件、层板与功能分区后续细化。
