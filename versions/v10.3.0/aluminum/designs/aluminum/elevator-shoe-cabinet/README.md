坐板下方由前后两根3030承梁、三根深向横撑、两侧18 mm支承板和后侧中部短支撑承托。两根底部横撑落在原底框内，支承侧板；抽屉左右导轨通过侧板安装。坐面承托与抽屉导轨分别表达，不能把抽屉滑轨承重当作坐面承重。

下层托盘底板离地56，上面68，透明防污垫顶面70；上层底板284、上面296。中间18 mm隔板位于252—270，上层托盘底与隔板保留14 mm间隙。坐面前梁下沿446，净高分别为252−70=182与446−296=150。前挡边闭合外表面X=382，完全抽出至682，踢脚条再凸出2。

两抽侧轨中心离地84、312，经垫片连接两侧支承板。物品随抽屉移动；固定轨不动，中轨半行程，动轨随抽屉全行程。脚触释放与300 mm滑轨为动作占位，尚未确定五金货号或额定承载。

底层板位于30—48，其余每层上方依次为30 mm型材承梁及18 mm层板。左侧后梁贯通1320，前梁在共享立柱处断开；两端连接深向梁，构成每层支承框。层板按1380 × 400外廓避让五根立柱，分块网格仅用于表达同一张开缺口的层板，中央主体净宽1320、净深340。新增三层含结构总计占用3×(160+30+18)=624，九层顶板上表面1980，顶框下沿2320，余高340先保留。

灯箱为深灰金属边框、暖白透光面板及深色“怪兽小屋”字样，固定于右侧顶梁下方。箱体在既有2350 mm外高内，背面预留低压LED灯带走线及可维护空间，电源放在干燥可检修处。当前灯光为外观示意，光源与固定件待选型。

三维图支持整体、左侧鞋层、灯箱近看、换鞋凳近看、俯视和左右正视；左侧鞋层标注净高。分区尺寸含左右立面、逐层净高表及踢脚抽剖面。层板、型材连接、导轨及坐面承载需按实物选型核算，本地预览不作为直接加工或承重认证图纸。
