# 电梯鞋柜 · 左右上层净高160与白色洞洞板

本地方案修订16。左侧第二层拖鞋格和右侧上层拖鞋抽均为实际净高160 mm。中隔板保持256 mm，左第二层板面464 mm，凳面484 mm。右侧下抽净高168 mm；两侧顶面因结构扣除不同而相差20 mm。左柜其余层随第二层增加40 mm顺移，框架外高仍为2350 mm。

详细尺寸页现明确区分400框架深、340结构净深、闭合门框422、铰链局部425，以及托盘外深300、箱内净深276。全部84根T槽型材（主体与承梁76根3030、门框8根2020）均有编号、截面、模型几何长、数量及闭合端点；金属收口占位和滑轨另列，可下载SVG编号图及CSV逐根表。

## 凳后白色洞洞板

凳面至灯箱下方改用白色喷粉金属洞洞板，设计外廓920 × 1650 × 2 mm。板下沿487、上沿2137，距凳面484和灯箱底2140各3 mm；沿Z=400—1320安装。孔径8、孔距25为建模预留，36列×65行。

后墙X=0至板背X=20预留20 mm供挂钩穿入，板前表面X=22；安装位于后型材30 mm厚度带内，六处连接片连接后侧立柱。凳上从板前表面至前型材内侧X=370净深348；至坐板前沿X=400可用坐深378。凳下结构净深仍为340，坐板外深仍为400，挂钩及挂物前突另扣。板厚、孔型、连接片和挂钩待实物选型，不据示意图确定挂载能力。

灯箱背后及凳下背板仍用原封板；凳面与抽屉高度沿用当前方案。

## 转角侧取与门板

转角朝换鞋凳侧的开口从484 mm起，首格左柜板面464，凳面484；侧取开口484—634，实际净高150。常规开口净宽340、净深340；上方按现有鞋层层位延续。顶格2140 mm以上受灯箱侧边局部遮挡80，剩余开口宽260。三维视角、尺寸图与逐根型材表均同步更新。

两端外侧封板亮蓝，背板、顶板和纵向分隔板炭黑。左红右黄两扇门分别通过外端铰链连接主体，独立打开0—90°；门扇457 × 2284，门框暂按20 × 20，色板暂按6。闭合门框表面到422，铰链节点略有凸出；每扇五处节点仅表达构造，具体五金与承载待选型。

对开黄门与踢脚抽在转角共用活动空间：抽出前先关闭黄门，打开黄门前先收回两抽。前挡边靠转角一端退让24，Z=428—1316；托盘本体仍宽850。预览自动表达使用次序，当前未配置实物机械联锁。

三维图、图纸及节点为本地方案预览，板厚、连接、铰链、滑轨及坐面承载需按实物选型复核。本次未发布，线上仍为住记 v10.3.0 的修订8；确认当前完成版本后再发布。
