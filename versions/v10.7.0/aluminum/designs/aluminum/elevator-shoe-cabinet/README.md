## 入槽计算基准

参考米思米HFS6-3030，有厂家截面和板件安装数据；不是确认采购型号。外截面30×30，槽口宽8，槽内深9。按厂家5厚板、3厚夹条和每端1安装间隙示例，每边插入9−1=8。

| 项目 mm | 左柜 | 右柜 |
| --- | ---: | ---: |
| 固定框架总深 | 420 | 360 |
| 两型材中心线间距 | 390 | 330 |
| 前后型材内边露出的净深 | 360 | 300 |
| 整板深度（含两边埋入槽内部分） | 376 | 316 |
| 每边插入 / 槽底余量 | 8 / 1 | 8 / 1 |
| 本基准板厚 / 夹条名义厚度 | 5 / 3 | 5 / 3 |

公式：板件深度=总外深−2×30+2×(9−1)；露出净深=总外深−2×30。420−60＋30=390是型材中心距；板厚在上下方向，不再加到前后深度上。

若在420外深中试放400深板，板边每侧须从型材内边插入20，超出本基准槽深9。按同一厂家安装关系，400整板对应外深444；400型材内边露出净深则对应外深460。这两种“400”不可混写。

板材材质、热胀冷缩、支承方式、承载及节点避让尚未定型。厂家示例每端1间隙未包含不同材料的热胀冷缩复核。整板还需按接头位置开缺口，不能按无缺口矩形直接下料；不得把厂家竖向面板的安装示例当作水平层板承重认证。

- 截面：https://us.misumi-ec.com/pdf/fa/2010/p2273.pdf
- 槽深、间隙、板厚、夹条及板件公式：https://in.misumi-ec.com/vona2/detail/110302263130/
