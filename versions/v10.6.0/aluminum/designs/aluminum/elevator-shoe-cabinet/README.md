## 左上六层可容纳的高度核算

本轮左上六个指定净高合计1010，每层30承梁＋18层板，六组共288。从起始板面824至顶梁底2320共有1496，剩余1496−1010−288=198 mm，可以放下。

左上从开放格上方开始，从下到上为：
**180 / 180 / 200 / 200 / 150 / 100 / 余198**，共7格。

右柜下方四格保持300 / 100 / 140 / 180；上方第5—8格保持，顶格用余高：
**300 / 100 / 140 / 180 / 200 / 200 / 220 / 220 / 余328**，共9格。

右柜最上两格调整为下220、上余328，合计净高220+328=548，等于原先300+248。左上六层合计1010，顶格198保持；柜体总高仍为2350。
